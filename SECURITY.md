# Security policy

This is a pre-1.0 local reference implementation. Only the latest main-branch version is maintained. Do not use the anonymous demo mode for sensitive or publicly accessible deployment.

Please report vulnerabilities through GitHub's private vulnerability reporting feature once the repository is published. Until that channel is enabled, do not open public issues containing secrets, customer records or exploit details; contact the repository owner through an established private channel. The maintainer must configure that channel before announcing a public release.

Include the affected version, reproduction steps, impact and suggested mitigation. There is no guaranteed response SLA at this stage.

See [the threat model](docs/security.md) for implemented controls and outstanding deployment responsibilities.
